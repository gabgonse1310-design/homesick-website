Homesick website redesign

Replace these files in the ROOT of the GitHub repository:
- index.html
- style.css

Add this new file in the ROOT:
- script.js

Do NOT move or rename the existing legal/support pages:
- privacy.html
- terms.html
- child-safety.html
- delete-account.html
- contact.html

The redesigned homepage links to those existing URLs, so Google Play links remain unchanged.

After uploading/committing:
1. GitHub repository -> Settings -> Pages
2. Keep Source: Deploy from a branch
3. Keep Branch: main
4. Keep Folder: /(root)
5. Wait a minute or two, then open:
   https://gabgonse1310-design.github.io/homesick/

The language switch stores the user's choice in the browser.
The page also follows the device light/dark appearance automatically.
